# Licenses – PoweredUp! base bodies

Checked 2026-10-01. Short version: **the exported bodies (GLB/.blend), the textures, and the walk clip
are CC0-compatible, so PoweredUp! Games can use, change and ship them in closed-source games,
commercially, with no attribution required.** No Meshy, Mixamo or other third-party content is in them.

| Component | License | Notes |
|---|---|---|
| Blender 4.5.14 LTS (tool) | GPL-2.0-or-later | It's a tool only. GPL doesn't cover files you make with it. |
| MPFB 2.0.17 add-on (tool, code) | GPL-3.0-or-later | `blender_manifest.toml`: `SPDX:GPL-3.0-or-later`. The code isn't shipped in any output. |
| MPFB / MakeHuman assets: base mesh hm08, targets/modifiers, proxies (`female1605`, `male1591`), eyes `low-poly`, eyebrow `eyebrow001`, rigs + weights (`game_engine`) | **CC0 1.0** | mpfb2 `LICENSE.md`: "The assets are defined as any data contributing to the output from MPFB … These assets have been released under CC0 1.0 Universal." It adds that the team "makes no claim whatsoever over output such as exports to files (FBX, OBJ, DAE …), renderings … saved model files." |
| MakeHuman system assets pack (`makehuman_system_assets_cc0.zip`) | **CC0** | All 94 entries in `packs/makehuman_system_assets.json` are `"license": "CC0"`. Asset files have headers like "explicitly released as CC0 in september 2020". |
| underwear04 pack (installed, **not used**) | CC0 | Socks only. |
| `textures/eye_teal.png`, `eye_amber.png`, `brow_mask.png` | CC0 (own work) | Generated by `scripts/make_textures.py`. The brow mask's alpha comes from the CC0 MakeHuman eyebrow001 texture. |
| Walk clip, underwear paint, slider morph set, all scripts | CC0 (own work) | Procedural keyframes (`scripts/walk_cycle.py`). No Mixamo or mocap. |
| three.js r180, gltf-transform 4.5.1, puppeteer-core (verification only) | MIT / MIT / Apache-2.0 | Not part of the assets. |

Sources:

- https://static.makehumancommunity.org/about/license.html

Watch out later: community asset packs on the MakeHuman site are **not all CC0**. For example,
`underwear03` is CC-BY, and many user-contributed assets are CC-BY. Check each pack's license column
before you use it in an outfit. Anything CC-BY needs attribution in the game credits.
